# Security Policy

## Repository Access and Contribution Policy

This repository is maintained as a proprietary project and is not open source.

### Access Control

Direct write access to all branches is restricted exclusively to the repository owner, Vidhya Walke.

External pull requests or code edits will not be reviewed or merged without prior direct communication and explicit authorization from the owner.

No third party is permitted to redistribute, re-license, or modify the source code without prior written consent.

### Collaboration and Inquiries

If you would like to collaborate, report an issue, or request access, please contact the owner directly before opening any pull request or issue.

- **Owner**: Vidhya Walke
- **GitHub**: https://github.com/vidhyawalke
- **Repository**: https://github.com/vidhyawalke/Timora-Digital-Worldwide-Clock-with-Pomodoro

### Reporting Vulnerabilities

Please report any security vulnerabilities directly to the owner via a GitHub private message rather than opening a public issue.
