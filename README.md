# Timora

A productivity dashboard built with React, featuring a live digital clock, worldwide timezone viewer, Pomodoro focus timer, real-time weather, and an embedded YouTube study player.

**Live App**: https://timora-digital-worldwide-clock-with.vercel.app/

**Repository**: https://github.com/vidhyawalke/Timora-Digital-Worldwide-Clock-with-Pomodoro

## Features

- Digital clock with 12-hour and 24-hour format options and a seconds progress bar
- World clock with real-time timezone lookup for any city globally
- Pomodoro timer with circular progress, session history, and chime alerts
- Live weather widget using automatic GPS detection with current conditions and a 2-day forecast
- Embedded YouTube player with curated study presets and custom URL support
- Background wallpaper picker with landscape, nature, and cityscape categories
- Dynamic card theming that adapts to the selected background color or image
- Progressive Web App support with 1-click installation on Windows, macOS, iOS, and Android

---

## Technology Stack

- React 18 with Vite
- Vanilla CSS with a custom design system
- Open-Meteo Geocoding and Weather APIs
- Lucide React for icons
- Web App Manifest and Service Worker for PWA support

## Local Development

```bash
# Clone the repository
git clone https://github.com/vidhyawalke/Timora-Digital-Worldwide-Clock-with-Pomodoro.git

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
