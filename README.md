## ✨ Features Overview

- **⏱️ Live Digital Clock**: Crisp 12-hour and 24-hour time readout with real-time seconds progress bar and local timezone badge.
- **🌍 Global World Clock**: Real-time geocoding API search with automatic timezone lookup, flag emojis, and day/night indicators for any city globally.
- **🍅 Pomodoro Station**: 25/5/15 Pomodoro timer with circular SVG progress, session logging, streak tracker, and Web Audio API chime sounds.
- **⛅ Live Weather Widget**: Automatic GPS geolocation detection, current temperature (°C / °F toggle), condition icons, and 2-day forecast via Open-Meteo API.
- **🎵 Focus Study Audio & Video**: Embedded study player loaded with 100% verified focus stations (Lofi Girl, Peaceful Piano, Rain & Thunder, Coffee Shop) and custom YouTube URL parser.
- **🎨 Chrome-Style Background Picker**: Curated collection of landscapes, nature, cyberpunk cityscapes, and dynamic luminance-adaptive dark/light solid color themes.
- **📲 Progressive Web App (PWA) & Desktop Hub**: 1-click desktop and mobile installation with step-by-step interactive platform guides for Windows, macOS, iOS, and Android.

- **Icons**: Lucide React
- **PWA**: Web App Manifest & Service Worker Cache

```bash

# Run local development server
npm run dev

# Build for production
npm run build
```
